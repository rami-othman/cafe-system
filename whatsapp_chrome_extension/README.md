# إضافة كروم لإرسال الفواتير عبر واتساب

تتركّب **مرة وحدة** على كروم تبعك (المسجّل فيه واتساب ويب):

1. افتح `chrome://extensions`
2. فعّل **Developer mode** (أعلى اليمين)
3. اضغط **Load unpacked** واختر هذا المجلد (`whatsapp_chrome_extension`)
4. افتح `https://web.whatsapp.com` بتبويب وخليه مفتوح

بعدها زر "إرسال عبر واتساب" بالـ POS بيستخدم هالتبويب نفسه: بيفتح محادثة العميل، بيلصق صورة الفاتورة، وبيضغط إرسال. إذا ما كان في تبويب واتساب مفتوح بيفتح واحد مرة وحدة.

- لازم يكون تطبيق الكاشير شغّال.
- الإضافة بتتواصل فقط مع `127.0.0.1:47618` (التطبيق على نفس الجهاز).
- إذا واتساب غيّر شكل صفحته وتوقفت الأتمتة، عدّل المحدّدات بأول `content.js`.
